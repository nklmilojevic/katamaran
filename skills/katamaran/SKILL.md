<!-- Installed by "kat skill setup". Remove it with "kat skill remove". -->

Run `kat skill show` and follow the guide it prints. The guide comes from the installed
`katamaran` CLI, so it describes the commands that version has. If `kat` is not on PATH,
run `/Applications/Katamaran.app/Contents/MacOS/katamaran skill show`.

If the command fails, the installed katamaran predates the guide: start with `kat status`,
then `kat --help` and `kat COMMAND --help`.
